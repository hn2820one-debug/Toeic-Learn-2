### 🎯 新浮現的三大「隱形殺手」

**殺手 1｜Mandative Subjunctive（虛擬語氣命令式）— 最致命**

這類題型在 Part 5/6 出現頻率極高（約 5–8% 的 Part 5 題量），您幾乎全錯：

- Q105 / Q111 / Q124 / Q144 / Q151 / Q163 / Q171 / Q181 / Q191 / Q201 / Q206 / Q211 / Q217
- 統一 Pattern：`recommend / suggest / demand / require / essential / mandatory / imperative / vital + that + S + V原形（或 be）`
- 您的錯誤傾向：用「過去式」或「三單現」代替原形 V（如 Q105 選 reviewed, Q144 選 keeps, Q217 選 follows）
- **這一個模組單獨可能拖掉 Part 5 約 5–7 題、Part 6 約 1–2 題**

**殺手 2｜倍數比較 twice/half/three times as X as**

- Q78 ❌ as large twice / Q274 ❌ as twice efficient as / Q278 ❌ as half large as / Q282 ❌ as twice efficiently as / Q287 ❌ as three times large as
- **5 題 0 正確**。正確結構永遠是 `倍數詞 + as + adj/adv + as`
- 這是一個「只要記一個公式就能 100% 解決」的題型，CP 值最高

**殺手 3｜Gerunds 觸發動詞 + 介系詞 + V-ing（確認大規模斷層）**

- 18 處失守，遠超存檔版估計
- 您的錯誤傾向：看到「to」就想 to V，而忽略「look forward TO / object TO / dedicated TO / be used TO」後面要接 V-ing
- 觸發動詞錯誤集中在：consider / suggest / postpone / delay / avoid / mind / forbid / afford + V-ing
